# Employee Payroll Management System

A console-based Employee Payroll Management System developed using Java, JDBC, and MySQL.

## Technologies Used

- Java
- JDBC
- MySQL
- Eclipse IDE

## Features

- Add Employee
- View Employees
- Search Employee
- Update Employee
- Delete Employee
- Add Payroll
- View Payroll
- Generate Payroll Report

## Database

The project uses MySQL with relational tables for:

- Departments
- Employees
- Payroll

Primary keys and foreign keys are used to establish relationships between the tables.

## Payroll Calculation

The system calculates:

- Total Earnings
- Total Deductions
- Net Pay

Payroll components include Basic Salary, HRA, Transport Allowance, Medical Allowance, Special Allowance, PF, ESIC, and Professional Tax.

- Object-Oriented Programming
- Classes and Objects
- Encapsulation

- SQL JOINs
- CRUD Operations
